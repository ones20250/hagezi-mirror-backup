# :zap: Official HaGeZi DNS Blocklist Mirror

Mirror of the DNS block list files from https://github.com/hagezi/dns-blocklists
                                 
For more details and a description of the individual lists, see the [README in the main repository](https://github.com/hagezi/dns-blocklists/blob/main/README.md).

### :dizzy: Support

If a domain seems to be blocked incorrectly, or you believe a domain should be blocked, please submit a report through the [blocklist repository’s issue tracker](https://github.com/hagezi/dns-blocklists/issues) or contact [support@hagezi.org](mailto:support@hagezi.org). You can also use the official public [Matrix support chat](https://matrix.to/#/#hagezi-support:tchncs.de?via=tchncs.de).

---

### :floppy_disk: Official mirrors <a name="mirrors"></a>

Official mirrors of the blocklist files:
                  
- https://hagezi-mirror.dnsbunker.org - updated every 4-8 hours and provided directly from the build system.
- https://gitlab.com/hagezi/mirror - updated once a day.
- https://codeberg.org/hagezi/mirror2 - updated once a day.
